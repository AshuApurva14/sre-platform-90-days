# our Week 1 exit test

Before starting Week 2, you should be able to answer this scenario:

A Linux application is unavailable.

And say:

1. Check process
2. Check port
3. Test application
4. Check permissions if relevant
5. Check service status if service-managed
6. Check logs
7. Identify likely cause
8. Take safe corrective action
9. Verify recovery
10. Document
11. Automate repeated checks

That is the capability Week 1 was designed to establish.
