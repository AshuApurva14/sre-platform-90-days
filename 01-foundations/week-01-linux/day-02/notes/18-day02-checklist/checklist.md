# Day 2 Completion Checklist

## Identity

- [ ] I can explain what a Linux user is.
- [ ] I can use `whoami`.
- [ ] I can use `id`.
- [ ] I understand UID and GID.

## Groups

- [ ] I understand why groups exist.
- [ ] I can list group membership.
- [ ] I can create a lab group.
- [ ] I can add a user to a supplementary group with `usermod -aG`.

## Ownership

- [ ] I can identify file owner and group with `ls -l`.
- [ ] I understand `chown`.
- [ ] I understand `chgrp`.

## Permissions

- [ ] I understand owner/group/others.
- [ ] I understand `r`, `w`, and `x`.
- [ ] I can translate `644`, `600`, and `755`.
- [ ] I understand directory `x` permission.
- [ ] I can use numeric `chmod`.
- [ ] I can use symbolic `chmod`.

## Privilege

- [ ] I understand why `sudo` is used.
- [ ] I avoid using `sudo` unnecessarily.

## Troubleshooting

- [ ] I can investigate `Permission denied`.
- [ ] I do not immediately use `chmod 777`.
- [ ] I can identify the intended owner/group/access.
- [ ] I can fix and verify a permission issue.

- [ ] Lab files committed.
- [ ] Commit message is meaningful.
