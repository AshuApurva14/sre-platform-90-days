## Day 4 must-know concepts

Before marking the recovery session complete, make sure you can explain:

`SIGINT`:

```bash
Ctrl+C
   ↓
interrupt foreground command
```


`SIGTERM`:

```bash

"Please terminate gracefully."
```

`SIGKILL`:

```bash
"Terminate immediately."

```

`SIGSTOP`:

```bash
Suspend process.
```

`SIGCONT`:

```bash
Continue suspended process.
```

`kill`:

```bash
Send a signal to a process.
```

`jobs`:

```bash
Send a signal to a process.
```

`bg`:

```bash
Continue a stopped job in background.
```

`fg`:

```bash
Continue a stopped job in background.

```
