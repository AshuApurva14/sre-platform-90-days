# Learn `systemctl status`

Run:

```bash

systemctl status cron
```

Study the output

Focus on:

```bash
Loaded:
Active:
Main PID:
```

You may see something similar to:

<img width="1694" height="721" alt="Image" src="https://github.com/user-attachments/assets/4280aaf3-f10a-4423-a3d7-c54dd2b99c0b" />

Now connect this to Day 3:

```bash
systemctl status
       ↓
Main PID
       ↓
ps

```

You are connecting service management with process management.
