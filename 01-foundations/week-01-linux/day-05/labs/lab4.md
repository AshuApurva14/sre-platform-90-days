## Practice `status`

Run:

```bash

systemctl status cron

```

```bash
systemctl is-active cron

```

For example:

```bash`
is-active
    ↓
Is the service currently active?

is-enabled
    ↓
Is it configured to start automatically?

```
This distinction is very useful.
