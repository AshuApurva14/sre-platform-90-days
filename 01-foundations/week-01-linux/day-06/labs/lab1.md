# Your first Bash script

Create:

```bash
nano scripts/hello.sh
```

Write:

```bash
#!/bin/bash

echo "Hello from Bash"
echo "Welcome to Week 1 Day 6"
```

Save and make executable:

```bash
chmod 755 scripts/hello.sh
```
Run:

```bash
./scripts/hello.sh
```
You should see:

```bash
Hello from Bash
Welcome to Week 1 Day 6
```
