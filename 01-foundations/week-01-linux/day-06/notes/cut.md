# cut

Try:
```bash
cut -d' ' -f1 labs/app.log
```
This extracts the first field separated by spaces.

Try:
```bash
cut -d' ' -f2 labs/app.log
```
This gives:
```bash

INFO
INFO
ERROR
```

This teaches you:
```bash
cut is useful when the data has a simple delimiter.

```
