# head and tail

Run:
```bash
head labs/app.log
```
Then:
```bash
head -3 labs/app.log
```
And:
```bash
tail labs/app.log
```
Then:
```bash
tail -3 labs/app.log
```
These are useful for large log files where you don't want to display everything.
