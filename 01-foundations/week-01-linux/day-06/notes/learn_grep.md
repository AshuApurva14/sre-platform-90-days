# grep

Find errors:
```bash
grep ERROR labs/app.log
```
Find warnings:
```bash
grep WARN labs/app.log
```
Case insensitive:
```bash
grep -i error labs/app.log
```
Count errors:
```bash
grep -c ERROR labs/app.log
```
This is one of the most useful Linux troubleshooting commands you'll learn.
