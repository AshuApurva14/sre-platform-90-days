# sed

Run:
```bash
sed 's/ERROR/ALERT/g' labs/app.log
```
This replaces `ERROR` with `ALERT` in the output.

Important:

This command doesn't modify the original file.

For now, use sed mostly for:
```bash
search/replace
line selection
simple transformations
```
