# wc

Run:
```bash
wc -l labs/app.log
```
This counts lines.

Then:
```bash
wc -w labs/app.log
```
counts words.

And:
```bash
wc -c labs/app.log
```
counts bytes.

For DevOps, you'll mostly use:
```bash
wc -l
```
for quick counting.
