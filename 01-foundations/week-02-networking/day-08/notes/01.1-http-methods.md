# HTTP Methods

HTTP methods describe what action the client wants to perform.

| Method | Purpose | Example |
|---|---|---|
| GET | Retrieve data | GET /users |
| POST | Create/send data | POST /users |
| PUT | Replace resource | PUT /users/123 |
| PATCH | Partially modify resource | PATCH /users/123 |
| DELETE | Delete resource | DELETE /users/123 |
| HEAD | Retrieve headers | HEAD /users |
| OPTIONS | Check supported methods | OPTIONS /users |

## Example API

GET /users

Retrieve users.

POST /users

Create a new user.

GET /users/123

Retrieve user 123.

DELETE /users/123

Delete user 123.
