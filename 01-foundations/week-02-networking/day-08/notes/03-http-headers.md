# HTTP Headers

Headers contain metadata about HTTP requests and responses.

Then create a small table:

| Header | Purpose |
|--------|---------|
| Host | Target hostname |
| Content-Type | Format of request/response body |
| Accept | Response format accepted by client |
| Authorization | Authentication credentials |
| User-Agent | Information about client |
| Content-Length | Size of body |

Then add your own examples.

## Content-Type

Example:
```bash
Content-Type: application/json
```
Meaning:

The HTTP body contains JSON.
