# Day 09 - HTTP Deep Dive

## Objective

Understand HTTP at a deeper level and learn how HTTP is used in real-world APIs and DevOps environments.

## Topics

- HTTP methods
- Safe and idempotent methods
- Request headers
- Response headers
- Request body
- Response body
- Authentication
- Authorization
- Bearer tokens
- Basic authentication
- Cookies
- Sessions
- Redirects
- REST APIs
- API troubleshooting

## Tools

- curl
- Python
- httpbin
- Git

## Labs

1. HTTP methods
2. HTTP headers
3. Authentication
4. Redirects
5. REST-style API requests

## Key Goal

Be able to inspect an HTTP request and explain:

```bash
Method + URL + Headers + Body
```
and understand the resulting:
```bash
Status + Headers + Body
```
