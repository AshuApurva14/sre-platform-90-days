# HTTP Methods

HTTP methods describe the action a client wants to perform on a resource.

## Common Methods

| Method | Typical Purpose |
|---|---|
| GET | Retrieve resource |
| POST | Create/process data |
| PUT | Replace a resource |
| PATCH | Partially update resource |
| DELETE | Delete resource |
| HEAD | Retrieve headers only |
| OPTIONS | Discover supported operations |

## Example

`GET /users -`  Retrieve users.

`POST /users -` Create a user.

`GET /users/123 -` Retrieve user 123.

`PATCH /users/123 -` Modify part of user 123.

`DELETE /users/123 -` Delete user 123.v
