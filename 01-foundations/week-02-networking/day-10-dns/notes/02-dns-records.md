# DNS Records

| Record | Purpose |
|---|---|
| A | IPv4 address |
| AAAA | IPv6 address |
| CNAME | Alias to another hostname |
| MX | Mail server |
| NS | Authoritative name server |
| TXT | Arbitrary text/verification information |

Then memorize:

```bash
A      → IPv4
AAAA   → IPv6
CNAME  → Alias
MX     → Mail
NS     → Name server
TXT    → Text/verification
```
