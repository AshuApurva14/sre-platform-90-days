# Data Tyeps in python

Python provides diff data types :

- int
- float 
- boolean
- string
- list
- non type

Each of the data types allow to use as per the requirement.

## Learn the important data types

You need these first:

### String

```python
hostname = "server01"
```
### Integer

```python
cpu = 75
```

### Float
```
load = 2.45
```

### Boolean

```
service_running = True
```

### List

```
servers = [
    "server01",
    "server02",
    "server03"
]
```

### Dictionary

Very important for automation:

```
server = {
    "hostname": "server01",
    "ip": "10.0.0.10",
    "status": "healthy"
}
```

You should become extremely comfortable with dictionaries.

You'll encounter structures like this constantly when working with:

```
AWS APIs
Kubernetes
Terraform
REST APIs
configuration
monitoring data
```
