# Learning Log — 2026-09-03

## Today's Goal

Understand Linux processes and signals.

## What I Learned

- A process has a PID.
- SIGTERM requests graceful termination.
- SIGKILL immediately terminates a process.
- `ps` shows running processes.
- `top` provides live process information.

## Commands Practiced

```bash
ps aux
top
kill -15 <PID>
kill -9 <PID>
