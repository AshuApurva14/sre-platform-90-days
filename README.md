# SRE & Platform Engineering — 90 Day Journey

A hands-on 90-day learning journey focused on building practical SRE and Platform Engineering skills.

## Goal

The goal is not to learn as many tools as possible.

The goal is to become capable of:

* Understanding how a request moves through a system
* Deploying software safely
* Monitoring system health
* Investigating failures using evidence
* Recovering services
* Automating repetitive operational work
* Building reliable deployment workflows

## Roadmap

### Month 1 — Foundations

* Linux
* HTTP
* DNS
* TLS
* TCP
* Git
* Python
* Docker

### Month 2 — Software Delivery

* Automated testing
* CI/CD
* Container registries
* Kubernetes
* Health checks
* Deployment strategies
* Rollbacks

### Month 3 — SRE & Reliability

* Metrics
* Logs
* Traces
* Prometheus
* Grafana
* SLOs
* Error budgets
* Alerting
* Incident response
* Chaos testing
* Reliability engineering

## Learning Method

Each topic follows:

**Learn → Practice → Break → Troubleshoot → Document → Automate**

Every week produces practical evidence:

* CI pipelines

* Runbooks

## Rule

I do not need to be perfect.

I need to keep moving.

**Never restart. Recover and continue.**

**Code → Test → Build → Containerize → Deploy → Observe → Fail → Diagnose → Recover → Document → Automate**
